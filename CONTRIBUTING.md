# Contributing to Ubuntu Toolkit

Thank you for your interest in contributing to Ubuntu Toolkit.

Ubuntu Toolkit is a collection of safe, modular and reusable scripts designed to automate common Ubuntu administration, maintenance, development and Git workflows.

The main goal of this project is to provide practical tools that are safe by default, easy to understand and suitable for everyday Linux users and developers.

## Code of Conduct

Contributors are expected to communicate respectfully and professionally.

Contributions should focus on improving the project, fixing problems, improving documentation, or adding useful functionality.

Harassment, discrimination, personal attacks and intentionally disruptive behavior are not acceptable.

## Before Contributing

Before creating a contribution:

1. Check the existing issues.
2. Check open pull requests.
3. Verify that the functionality does not already exist.
4. Review the repository documentation.
5. Make sure your proposed change follows the project's safety principles.

For significant changes, open an issue first to discuss the proposed implementation.
